# Persian Product Reviews Dataset

A cleaned Persian product review dataset prepared for research and public release.

## Statistics

- Total rows: **237855**
- Unique comments: **237855**
- Average comment length: **25.86** words
- Median comment length: **15.00** words
- Min comment length: **3** words
- Max comment length: **200** words

## Labels
- positive
- neutral
- negative

## Cleaning
- Persian normalization
- URL and email removal
- Emoji removal
- Invisible/control character removal
- Noise filtering
- Duplicate removal
- Quality filtering by length

## Intended Use
Sentiment analysis, text classification, and Persian NLP research.

## Notes
This dataset is cleaned for research use and does not include raw usernames or personal identifiers.
